# FAQ

## My slash commands don't show up

Slash registration is a separate step from running the bot:

```bash
npx adjskit sync
```

During development, set `DISCORD_GUILD_ID` — guild-scoped commands appear **instantly**. Global commands (no guild id) can take up to an hour to propagate to every server.

## `ephemeral: true` stopped working

discord.js v14 deprecated the option in favor of flags:

```ts
import { MessageFlags } from 'discord.js';

await interaction.reply({
  content: 'Only you can see this',
  flags: MessageFlags.Ephemeral,
});
```

## Do I need the Message Content intent?

Only for prefix commands. Enable **Message Content Intent** in the developer portal (*Bot → Privileged Gateway Intents*). If your bot is slash-only, set `prefix: null` in config and skip the intent entirely.

## TypeScript or JavaScript?

Both are first-class — pick at scaffold time (`--lang ts|js`). The generated configs, stubs, and sync script match your choice. The examples in these docs use TypeScript; drop the type imports for JS.

## I edited a file and `adjskit update` wants to overwrite it

You won't be surprised: modified managed files are **skipped** by default. Use `--dry-run` to see what would change, and `--force` only when you truly want the framework version back. See [Project anatomy](/docs/guides/project-anatomy/).

## Where do I add my own env variables?

Extend the built-in zod schema in `src/config.ts`:

```ts
const envSchema = defaultEnvSchema.extend({
  DATABASE_URL: z.string().min(1, 'DATABASE_URL is required.'),
});

export const env = defineEnv(envSchema);
```

Validation errors print at startup before anything connects.

## What happens when a listener throws?

Rejections inside event listeners are caught and logged instead of crashing the process — one bad handler can't take the bot down. Command errors surface through the configurable `commandError` message.
